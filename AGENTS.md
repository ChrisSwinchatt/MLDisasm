## Commit message style

```
first file changed: second file: Brief imperative description of the changes

Longer description still in imperative voice

Co-authored-by: Agent (model)
Signed-off-by: Human developer <email address>
```


Example:
```
AGENTS.md: Add commit message style

Add a commit message style guide for agents

Co-authored-by: DeepSeek (deepseek-pro-v4)
Signed-off-by: Chris Swinchatt <chris@swinchatt.dev>
```

NB: Ensure all lines are <=72 characters long
